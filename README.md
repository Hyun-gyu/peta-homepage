# PETA Homepage

Static landing page prototype for PETA, an industrial AI partner for manufacturing and plant sites.

## Local Preview

Open `index.html` in a browser.

## Deployment

This folder is ready for static hosting on Cloudflare Pages or GitHub Pages.

Current SEO placeholder URL:

```txt
https://peta-ai.pages.dev/
```

If the deployed URL changes, update:

- `index.html` canonical URL and Open Graph URLs
- `robots.txt`
- `sitemap.xml`
